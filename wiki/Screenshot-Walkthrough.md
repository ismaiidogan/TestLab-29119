# Screenshot Walkthrough

Ordered UI tour of TestLab 29119. Screenshots are hosted in the main repository under `docs/screenshots/`.

> **Note for instructors:** Deliverable item 3 (physical game photos) does not apply to this web application. This appendix substitutes an ordered visual walkthrough.

---

## 1. Welcome — Player profile

![Welcome screen](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/01-welcome.png)

Enter name and school, then **Start Mission**. Profile data appears on the certificate and leaderboard.

---

## 2. Tutorial — Three categories

![Tutorial three categories](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/02-tutorial-categories.png)

Introduces Specification-Based, Structure-Based, and Experience-Based technique groups (ISO/IEC 29119-4).

---

## 3. Tutorial — Clause 4 selection criteria

![Tutorial Clause 4](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/03-tutorial-clause4.png)

Explains risk, objectives, test levels, and organizational context—foundation for Phase 3.

---

## 4. Phase 1 — Classify

![Phase 1 classify](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/04-phase1-classify.png)

Drag fifteen technique cards into the three category drop zones.

---

## 5. Phase 2 — Scenario with ISO 25010 badge

![Phase 2 scenario](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/05-phase2-scenario.png)

Nine multiple-choice scenarios; each shows an ISO/IEC 25010 quality characteristic badge.

---

## 6. Phase 3 — Test strategy

![Phase 3 strategy](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/07-phase3-strategy.png)

Select up to five techniques per project given risk, budget, timeline, team, and documentation constraints.

---

## 7. Phase 4 — Test case selection

![Phase 4 test cases](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/08-phase4-testcases.png)

Choose required EP and BVA test cases via checkboxes.

## 8. Results — Score and grade

![Results screen](https://raw.githubusercontent.com/ismaiidogan/TestLab-29119/main/docs/screenshots/09-results.png)

Total score, grade tier, phase breakdown, misconceptions, and certificate download.
