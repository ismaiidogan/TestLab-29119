# Pedagogy

This page summarizes why TestLab 29119 is an effective approach for teaching **ISO/IEC 29119-4** and **ISO/IEC 25010** in an academic or professional development context.

---

## The problem with passive learning

ISO/IEC 29119-4 defines many test design techniques across three categories. Students who only read the standard often:

- Confuse technique **names** with technique **purpose**  
- Treat black-box vs white-box as equivalent to the standard’s three categories  
- Assume equivalence partitioning **replaces** boundary value analysis  
- Believe **100% coverage guarantees** defect detection  

ISO/IEC 25010 adds quality-characteristic context that lectures alone rarely connect to technique choice.

---

## Serious-game approach

TestLab 29119 uses **active learning** through role-play as a **Test Manager**. Cognitive demand increases across four phases:

| Phase | Cognitive level | Activity |
|-------|-----------------|----------|
| 1 | Remember / understand | Classify techniques |
| 2 | Apply | Choose techniques for scenarios |
| 3 | Evaluate | Justify strategy under constraints |
| 4 | Create | Select EP/BVA test cases |

This progression reduces the “illusion of competence” from passive reading.

---

## Alignment with the standards

| Mechanism | Pedagogical benefit |
|-----------|---------------------|
| Phase 1 classification | Corrects category misconceptions early |
| Phase 2 scenarios + 25010 badges | Links techniques to quality goals |
| Phase 3 projects | Teaches Clause 4 judgment without a fixed algorithm |
| Phase 4 test cases | Moves from “which technique?” to “what to test?” |
| Misconception log | Supports reflective learning on the results screen |
| Comparison questions | Addresses common confusions (EP/BVA, ET/AHT, SC/BC) |

See [ISO Standards Alignment](ISO-Standards-Alignment) for clause-level mapping.

---

## Assessment design

- **500-point rubric** with transparent phase weights  
- **Percentage-based grades** (ISO Master through Trainee)  
- **Downloadable certificate** as a completion artifact  
- Formative feedback after every decision  

Details: [Scoring and Certification](Scoring-and-Certification).

---

## Limitations (transparent scope)

| Limitation | Implication |
|------------|-------------|
| Client-side leaderboard | Not suitable for high-stakes competition without a server |
| English UI | May require support for non-English classrooms |
| Browser required | No native mobile app |
| Simplified strategy scoring | Illustrates judgment; not a replacement for full risk-based test planning in industry |

These limits are acceptable for classroom and self-study use.

---

## Conclusion

TestLab 29119 transforms ISO/IEC 29119-4 from a document to memorize into a **practice environment** where learners classify, apply, strategize, and design under realistic constraints—while ISO/IEC 25010 tags show *why* a technique fits a given quality goal.
