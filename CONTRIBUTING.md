# Contributing

TestLab 29119 is an **academic course deliverable** (SENG 436, Çankaya University). The primary distribution is the live game and PDF documentation in `docs/`.

## Running locally

```bash
npm install
npm start
```

Open http://localhost:3000

Optional: `npm test` (Playwright smoke tests).

## Reporting issues

- **Bugs or gameplay issues:** Use [GitHub Issues](https://github.com/ismaiidogan/TestLab-29119/issues) with the bug report template.
- **Security vulnerabilities:** See [SECURITY.md](SECURITY.md) — do not file public issues for security reports.

## Pull requests

Small fixes (typos, broken links, accessibility) are welcome. For large changes, open an issue first to discuss scope.

## Documentation

- Player guide: [Wiki](https://github.com/ismaiidogan/TestLab-29119/wiki)
- Course PDFs: `docs/USER_MANUAL.pdf`, `docs/TEACHING_EFFECTIVENESS.pdf`

Thank you for your interest in the project.
