# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest `main` branch | Yes |

TestLab 29119 is a static browser game deployed on GitHub Pages. Only the current `main` branch is maintained.

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue.

**Preferred:** [Report a vulnerability](https://github.com/ismaiidogan/TestLab-29119/security/advisories/new) (private advisory).

**Alternative:** Contact the repository owner with:

- Description of the issue and impact
- Steps to reproduce
- Affected URL or file paths (if known)

We aim to acknowledge reports within **7 days** and provide a fix or mitigation plan when applicable.

## Scope notes

- Scores and leaderboard data use browser `localStorage` only; there is no server-side validation by design.
- Third-party resources (e.g. Google Fonts) follow their providers’ security models.

Thank you for helping keep this project secure.
